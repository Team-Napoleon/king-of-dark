Put the dialogue font here, named exactly:  PixelifySans.ttf

Get it (free, SIL Open Font License):
  https://fonts.google.com/specimen/Pixelify+Sans  ->  "Get font"  ->  "Download all"
  Unzip, take the file "PixelifySans[wght].ttf" and rename it to PixelifySans.ttf

If this file is missing the game still works: it uses the Google Fonts link in index.html,
and if you are offline it falls back to Trebuchet MS / Verdana.
